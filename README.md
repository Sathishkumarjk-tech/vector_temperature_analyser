# Vector Temperature Analyzer

**Aim:** Use R vectors to analyze one week of temperatures.

**Concepts:** Vectors, vectorized calculations, `mean()`, `max()`, `min()`, `which.max()`, `which.min()`, logical indexing, `seq()`, and `abs()`.

**Run:** Open the folder in RStudio and run `source("main.R")`. The program saves `temperature_report.csv`.
